# OvenMediaEngine Documentation

Welcome to the documentation hub for **OvenMediaEngine** (OME) and **OvenMediaEngine Enterprise** (OME-E).

:::info[Migration in progress]

This documentation site is being migrated from GitBook. During the transition the canonical sources remain:

- OSS: [docs.ovenmediaengine.com](https://docs.ovenmediaengine.com/)
- Enterprise: [docs.enterprise.ovenmediaengine.com](https://docs.enterprise.ovenmediaengine.com/)

Old URLs will 301-redirect to their new locations once the migration completes.

:::

## What's in here

### Open-Source Edition
Configuration, deployment, ingest protocols, output protocols, transcoding, recording, REST API, clustering, and operations for the open-source OvenMediaEngine.

### Enterprise Edition
Additional capabilities for OvenMediaEngine Enterprise, including commercial codecs, DRM integration, advanced monitoring, and enterprise REST API.

## Where to start

If you're new, start with the **Getting Started** guide (coming soon). For protocol-specific tuning, jump into **Ingest** or **Output** sections.

For commercial support and SLA-backed deployments, see [OvenMediaEngine Enterprise](/ome-enterprise) or [contact us](/contact).
