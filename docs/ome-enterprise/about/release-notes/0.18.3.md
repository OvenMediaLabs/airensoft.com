## 0.18.3.3-1 (July 24, 2025)

### OvenMediaEngine

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.14.9 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0-1 or later.

#### \[Fixed]

* Fixed an issue where playback could restart under certain conditions during WebRTC streaming.
* Fixed an issue where video encoding quality would intermittently degrade.
* Fixed potential malfunction of `SignedPolicy` and `AdmissionWebhooks` in SRT.

### Web Console

#### \[Improved]

* Improved to handle cases more gracefully when the REST API is not configured in OvenMediaEngine Enterprise.

## 0.18.3.2-1 (July 16, 2025)

### OvenMediaEngine

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.14.9 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0-1 or later.

#### \[Added]

* Added 32/64 byte aligned addresses and data padding to prevent decoding crashes.
* Added SHA-2 support to `SignedPolicy`, `AdmissionWebhooks`, and `Alert`.

#### \[Fixed]

* Fixed issue where A/V sync could be incorrect when `GenerateAudioPTS` option is enabled.

## 0.18.3.1-1 (July 11, 2025)

### OvenMediaEngine

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.14.9 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0-1 or later.

#### \[Added]

* Added support for dynamic alert rules management and configuration.
* Added LL-HLS and HLS-ready detection to alert.

#### \[Fixed]

* Fixed a regression bug where the start property of an Item in `ScheduledChannel` was not working.
* Fixed an issue where a track might not play due to track ID conflicts when using multitrack video in E-RTMP.
* Fixed an issue where playback could be unstable when both `GenerateAudioPTS` and `TimestampMode` settings are enabled.

#### \[Improved]

* Improved `streamid` handling in SRT Provider/Publisher to use host name instead of vhost ([#1847](https://github.com/AirenSoft/OvenMediaEngine/discussions/1847), [#1848](https://github.com/AirenSoft/OvenMediaEngine/discussions/1848)).

#### \[Changed]

* Split the `StreamStatus` event in Alert into separate events for ingress and egress.

### Web Console

#### \[Added]

* Added a feature to detect and notify changes in `Server.xml` that require an OvenMediaEngine Enterprise restart.
* Added support for dynamically updating Alert Rules without restarting OvenMediaEngine Enterprise.

***

## 0.18.3.0-1 (Jun 26, 2025)

### OvenMediaEngine

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.14.9 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0-1 or later.

#### \[Added]

* Added `TimestampMode` to `<provider>` (Options: `ZeroBased`, `SystemClock`, `Original`).
  * [Go to the related guide](../../features/high-availability/origin-redundancy.md#timestampmode-settings--01830)
* Added `PacketSilenceTimeoutMs` to Push Provider (Default: 0, ignored).
  * [Go to the related guide](../../features/high-availability/origin-redundancy.md#packetsilencetimeoutms-settings--01830)

#### \[Fixed]

* Fixed an issue where `ServerTimeBasedSegmentNumbering` might not be synchronized in HLS.
* Fixed an intermittent issue where a connection failure could occur when starting RTMP Push.

### Delivery

#### \[Fixed]

* Fixed an issue where the delivery system did not work properly in certain environments.
