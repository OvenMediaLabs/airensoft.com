## 0.18.2.1-1 (Jun 18, 2025)

### OvenMediaEngine

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.14.9 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0-1 or later.

#### \[Added]

* Added E-RTMP (Enhanced RTMP) support.
* Added `/v2/stats/*` APIs.
* Added `StreamStatus` rule to the Alert.

#### \[Fixed]

* Fixed an issue where XML-based event generation was intermittently stopping.
* Fixed an issue where Opus audio would break upon OVT reconnection.

## 0.18.2.0-1 (May 29, 2025)

### OvenMediaEngine

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.14.9 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0-1 or later.

#### \[Added]

* Added support for inserting SEI events only at Keyframes.
* Added sending AMF `OnTextData` event by XML configuration.

#### \[Improved]

* Improved the Scheduled Channel to start playback from the correct position in the `Item` based on the current time and the `scheduled` attribute in the `Program`.

#### \[Changed]

* Changed to support Xilinx U30MA SDK v3.1 rc4.
  * _Please update the Xilinx U30MA driver version on the host._

### Web Console

#### \[Changed]

* Changed to modify only `Server.xml` without restarting the OvenMediaEngine when applying settings.
