## 0.19.1.1-1 (September 16, 2025) <a href="#id-1-1" id="id-1-1"></a>

### OvenMediaEngine <a href="#ovenmediaengine" id="ovenmediaengine"></a>

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.19.1 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0 or later.

#### \[Added]

* Added support for inserting `onUserDataEvent` into AMF0 Message.
  * [Jump to the related guide](../../features/workflow-integration-and-external-system-connectivity/amf0-message-insertion.md#onuserdataevent)
* Added the Dump feature to Legacy HLS.
* Added `ThreadPerSocket` option.
* Added a Date Header for all HTTP responses.

## 0.19.1.0-1 (August 29, 2025) <a href="#id-0-1" id="id-0-1"></a>

### OvenMediaEngine <a href="#ovenmediaengine" id="ovenmediaengine"></a>

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.19.1 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0 or later.

#### \[Added]

* Added image overlay feature.
* Added H.265 codec support to the RTSP Pull provider.

#### \[Fixed]

* Fixed a crash issue when recording to a file.
* Fixed an issue where malformed data in RTMP could cause abnormal termination.

#### \[Improved]

* Improved to support certain RTSP cameras that transmit in a non-standard way.

### Web Console <a href="#ovenmediaengine" id="ovenmediaengine"></a>

#### \[Fixed]

* Fixed an issue where the stream list was not displayed in certain situations.

#### \[Improved]

* Improved OvenMediaEngine REST API call handling to reduce unnecessary calls.
