## 0.16.8.0-1 (July 19, 2024) <a href="#id-0-1" id="id-0-1"></a>


:::warning

Urgent Patch - OvenMediaEngine 0.16.7 is unusable and has been removed.

:::


### OvenMediaEngine

#### **\[Compatibility]**

* Compatible with dependencies (`prerequisites.sh`) installed in 0.14.9 or later.
* Compatible with `Server.xml` used in 0.12.6 or later.
* Compatible with version 0.15.12 or higher of Origin or Edge.

#### **\[Fixed]**

* Removed code for debugging that prevented WebRTC playback in the 0.16.7 release.

### Web Console

#### **\[Added]**

* Added features to inquire server information on the Settings page.
* Added features to modify the `Server.xml` file directly from the Settings page.
  * Enabled application of all edited items, allowing temporary saving during modifications.
  * Currently, configurable items include:
    * `<Server><Name>` - [_Configuration_](https://airensoft.gitbook.io/ovenmediaengine/configuration#server)
    * `<Server><Type>`&#x20;
    * `<Server><IP>`&#x20;
    * `<Server><PrivacyProtection>`&#x20;
    * `<Server><StunServer>`&#x20;
    * `<Server><Modules>`&#x20;
    * `<Server><Bind>` - [_Configuration_](https://airensoft.gitbook.io/ovenmediaengine/configuration#bind)
    * `<Server><Managers>` - [_Configuration_](https://airensoft.gitbook.io/ovenmediaengine/rest-api#managers)
    * `<Server><Alert>` - [_Configuration_](https://airensoft.gitbook.io/ovenmediaengine/alert#configuration)
