## 0.20.0.1-1 (November 14, 2025) <a href="#id-1-1" id="id-1-1"></a>

### OvenMediaEngine <a href="#ovenmediaengine" id="ovenmediaengine"></a>

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.19.1 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0 or later.

#### \[Added]

* Added an option to set the `TimestampMode` for RTMP, SRT, and MPEG-TS push publisers.

#### \[Improved]

* Improved the wrap-around algorithm for the time value inside the TS container.

#### \[Fixed]

* Fixed an issue where the recorded file sometimes got corrupted when the stream ended.

### Web Console <a href="#ovenmediaengine" id="ovenmediaengine"></a>

#### \[Added]

* Added a feature to configure `<Defaults>` setting in `Server.xml` from the settings page of the Web Console.

#### \[Fixed]

* Fixed an issue where the settings page would sometimes not display correctly.

## 0.20.0.0-1 (November 03, 2025) <a href="#id-0-1" id="id-0-1"></a>

### OvenMediaEngine <a href="#ovenmediaengine" id="ovenmediaengine"></a>

#### \[Compatibility]

* Compatible with dependencies installed via `prerequisites.sh` in version 0.19.1 or later.
* Compatible with the `Server.xml` configuration format used in version 0.12.6 or later.
* Compatible with Origin and Edge versions 0.18.0.0 or later.

#### \[Added]

* Added Session Management features.
  * [Jump to the related guide](../../features/workflow-integration-and-external-system-connectivity/session-management-webrtc-only.md)
  * [Jump to the related API (List and Terminate Sessions)](../../features/rest-api/v1/session.md) / [the related API (Statistics)](../../features/rest-api/v1/statistics/current/)
* Added Realtime Speech-to-Text subtitle feature (_beta_).
  * [Jump to the related guide](/docs/ome/subtitles/realtime-speech-to-text)
* Added API to query supported codecs.
  * [Jump to the related API](../../features/rest-api/v2/internals/codecs.md)
* Added [Enhanced Alert](../../features/operations-and-monitoring/enhanced-alert.md) for transcoder creation failures.
* Added SCTE-35 event insertion during SRT push.
  * [Jump to the related guide](../../features/workflow-integration-and-external-system-connectivity/ad-markers.md#scte-35-event-insertion-srt)
* Added Subtitle feature in LLHLS.
  * [Jump to the related guide](/docs/ome/subtitles)

#### \[Improved]

* Improved [Get Stream Info API](/docs/ome/rest-api/v1/virtualhost/application/stream#get-stream-info) and [Enhanced Alert](../../features/operations-and-monitoring/enhanced-alert.md) to include metadata for Passthrough (bypass) output streams.
* Improved `ScheduleChannel` to preload scheduled files to reduce file switching time.
* Improved the transcoder to optimize memory usage.
* Improved support for `VideoIndexHint`/`AudioIndexHint` even in Multiplex-only Playlists.

#### \[Fixed]

* Fixed an issue where the Fallback Program was not updated in certain situations in `ScheduleChannel`.
* Fixed `ScheduleChannel` to make the Fallback Program always start playing from the first item.
* Fixed the crash issue when releasing the NVIDIA encoder.
* Fixed memory leak issue when using multiple GPUs.
