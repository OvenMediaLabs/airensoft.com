OvenMediaEngine Enterprise 0.16.7.# is no longer supported. Please use 0.16.8.# or higher.

:::


## 0.16.7.1-1 (July 18, 2024)

### OvenMediaEngine

#### **\[Compatibility]**

* Compatible with dependencies (`prerequisites.sh`) installed in 0.14.9 or later.
* Compatible with `Server.xml` used in 0.12.6 or later.
* Compatible with version 0.15.12 or higher of Origin or Edge.

#### \[Changed]

* Changed to support multiple parameters when executing the `ome_launcher` script.

***

## 0.16.7.0-1 (July 18, 2024)

### OvenMediaEngine

#### **\[Compatibility]**

* Compatible with dependencies (`prerequisites.sh`) installed in 0.14.9 or later.
* Compatible with `Server.xml` used in 0.12.6 or later.
* Compatible with version 0.15.12 or higher of Origin or Edge.

#### **\[Added]**

* Added NVIDIA Driver installation script for Rocky Linux.
