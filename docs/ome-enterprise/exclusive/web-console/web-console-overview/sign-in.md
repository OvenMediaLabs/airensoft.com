## Accessing the Web Console

As described in the [Getting Started with Web Console](../getting-started-with-web-console.md) section above, users can access the Web Console using the URL pattern below:

```
http://<OME_HOST_IP>:<OS_SERVER_PORT>
```

<table><thead><tr><th width="239">Env</th><th>Description</th></tr></thead><tbody><tr><td>OME_HOST_IP</td><td>IP address of the server running OvenMediaEngine Enterprise</td></tr><tr><td>OS_SERVER_PORT</td><td>Service port on which the Web Console will run</td></tr></tbody></table>

![](../../../images/07_Sign.png)

If you access `http://<OME_HOST_IP>:<OS_SERVER_PORT>` and see a page like the image above, you can sign in using the default password. After your first login, you can change the default password through the [Change Password](change-password.md) menu.


:::tip

The default password is set to `ovenstudio`, and more details can be found in the [Admin Password](../getting-started-with-web-console.md#admin-password) section.

:::
