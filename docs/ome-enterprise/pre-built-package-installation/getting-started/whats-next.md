You have installed OvenMediaEngine Enterprise, published your first stream, secured it with TLS, and configured adaptive bitrate streaming. Here are the areas to explore next.

## How to Configure OvenMediaEngine

OvenMediaEngine is configured through `Server.xml`. The configuration covers port bindings for ingest and egress protocols, virtual hosts, domain and TLS settings, and application-level settings such as providers, publishers, and output profiles.

- [Configuration Structure](../configuration-structure/README.md)

## Web Console

The Web Console provides a visual interface for managing streams, configuring OvenMediaEngine, and monitoring events in real time.

- [Web Console Overview](../../exclusive/web-console/README.md)

## Features

- [Live Source](../../features/live-source/README.md): Pull streams from external sources and manage live inputs.
- [Streaming & Distribution](../../features/streaming-and-distribution/README.md): Configure egress protocols, CDN integration, and delivery options.
- [Transcoding & Processing](../../features/transcoding-and-processing/README.md): Set up encoding profiles, ABR, and media processing pipelines.
- [Access Control & Security](../../features/access-control-and-security/README.md): Protect streams with authentication and access policies.
- [High Availability](../../features/high-availability/README.md): Configure origin-edge clustering and failover.
- [Operations & Monitoring](../../features/operations-and-monitoring/README.md): Monitor server health, logs, and stream metrics.
- [REST API](../../features/rest-api/README.md): Control and query OvenMediaEngine programmatically.

There is much more to explore. Check the [Feature Index](../../about/feature-index.md) for a full list of capabilities, or see the [Release Notes](../../about/release-notes/README.md) for the latest updates.
