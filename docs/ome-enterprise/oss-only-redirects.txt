# OSS-only link redirects (consumed by ovenmedialabs.com's
# scripts/gen-enterprise-shared.js during docs sync).
#
# A `dup:` page copies its body from the OSS manual. If that OSS body
# links to an OSS page that is INTENTIONALLY OSS-only (no Enterprise
# twin), the copied link has nowhere to go on the Enterprise side. List
# those here so the generator rewrites them on purpose instead of
# aborting (fail-closed).
#
# Any OSS-only link NOT listed here makes the docs sync stop loudly —
# that is deliberate, so genuine mistakes / renames are caught, not
# deployed.
#
# Format, one per line:
#   <oss path>  =>  <enterprise path>     # send reader to that ENT page
#   <oss path>  =>  @oss-site             # send reader to the OSS site section
#
# Paths are repo-relative (oss = docs/ome/..., enterprise =
# docs/ome-enterprise/...). Comments start with '#'. Blank lines ignored.
